# 双人标注与仲裁指南

## 标注单位

每条 JD 独立标注下列字段：

- 原始岗位名、规范岗位名、公司、地区、行业。
- 职责原文跨度。
- 必备技能、加分技能、仅提及技能；每项保存原文跨度。
- 与已有图谱节点的关系：`exact`、`curated_alias`、`unresolved`。语义相似不得直接标为 exact。

每份政策/报告独立标注“主张—证据跨度—支持岗位/技能—时间—发布方”。不标注无法在原文中定位的常识推断。

## 独立性与仲裁

1. 标注员 A 和 B 先独立完成，不查看对方结果。
2. 程序以文档 ID、字段和字符区间生成分歧表。
3. 仲裁员仅处理分歧，记录仲裁原因，不覆盖 A/B 原始标注。
4. 冻结金标后计算字段抽取 Precision/Recall/F1、近重 Precision、RAG Recall@20、新岗位 Precision@10 和技能变化 F1。

## 新岗位判定

标注员不根据“名字新颖”判定。需检查标题、核心职责和技能组合是否与现有岗位原型实质不同，并保存反例节点。回溯测试必须使用时间切分：预测时不可向模型暴露之后的人社部发布文件。

## 验收模板

`evaluation.py` 提供集合精召率、Precision@k、Recall@k 和成对去重 Precision 计算。真实标注结果必须由两位标注员与仲裁员签字后再写入测试报告；合成 fixture 的自测结果不能替代真实验收数字。
