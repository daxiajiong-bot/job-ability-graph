## 4. 总体架构

**页面标题：** 分层架构：前端 / API / 应用 / 领域 / 基础设施

**一句话结论：** DDD 分层 + 适配器模式，智能组件全部可插拔、可降级。

```
表现层   React 19 + Vite + Ant Design + ECharts + Three.js（10 个页面）
API 层   FastAPI /api/v1（文档/画像/匹配/报告/图谱/检索/治理/认证/趋势桥接）
应用层   use_cases 编排（文档→画像→匹配→报告→建议；混合召回）
领域层   实体 + 端口接口 + 领域错误
基础设施 SQLite｜Neo4j｜Ollama｜Qwen3-Embedding｜PaddleOCR｜文件治理
```

**要点：**
- 前端 10 页面：仪表盘 / JD / 简历 / 匹配 / 推荐 / **岗位发现** / 历史 / 图谱 / 星图 / 设置
- API 层新增 `/trend/*`：只读桥接 JobTrend 分析产物（新岗位/技能更新/趋势特征/审核队列）
- 基础设施 6 大件，全部本地可跑（无需云）
- mock 降级：任一服务不可用，功能降级不崩溃

## 7. 核心流程②：智能推荐（混合召回）

**页面标题：** 语义召回 + 关键词召回 + LLM 精排

**一句话结论：** 微调嵌入模型先"懂语义"，LLM 再"精打分"。

```
输入（简历→岗位 / JD→简历）
→ ① Qwen3-Embedding-4B 语义召回（向量 Top-K）
→ ② SQL 技能重叠召回 → 合并去重（recall=hybrid）
→ 筛选（地区/行业/薪资/年限）
→ 前 N 条 LLM 打分，其余重叠度兜底
→ 排序去重 → Top-N（结果缓存）
```

**要点：**
- 语义召回解决"关键词对不上但意思相近"的漏召回
- 结果可解释：技能重叠数 + 匹配/缺失技能 + 推荐理由
- 索引缺失时自动降级 `recall=sql`，不影响使用

**配图建议：** 双通道召回漏斗图

## 9. 核心流程④：动态演化

**页面标题：** 图谱自我进化 + 前端"岗位发现"

**一句话结论：** 离线发现趋势 → 人工审核 → 增量合并进图谱 → 前端一键查看新岗位与技能变化。

```

→ 一键跳转 /graph?q=岗位名 图谱检索高亮
```

**要点：**
- 样例演化：AI Agent 安全评测工程师 → REQUIRES_SKILL → 红队测试 / RAG / Agent…
- 只读集成 + append-only 增量，杜绝污染队友图谱

- 闭环完整：发现 → 审核 → 合并 → 前端展示 → 图谱联动

**一句话结论：** 结构化抽取 + 证据约束 + 权威白名单，从源头防控 AI 幻觉。

## 11. 关键技术②：嵌入模型微调与部署

**页面标题：** Qwen3-Embedding-4B LoRA 微调 + 8-bit 量化落地

**一句话结论：** 领域微调显著提升检索质量，量化后 8GB 显存可部署。

**要点：**
- 方案：共享双塔 + LoRA 对比学习（GradCache 省显存）
- 指标：测试集 Recall@10=97.9% / NDCG@10=95.8%，正样本平均排名 6.38→3.14
- 部署：bitsandbytes 8-bit 量化（~4GB 显存）+ 100 条索引实测 `recall=hybrid`
- 边界：结果标注为"合成受控基准"，不冒充真实场景准确率（诚实可验证）

**配图建议：** 训练流程图 + 指标对比表/柱状图
