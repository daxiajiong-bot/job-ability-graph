## 四、投产缺失清单

### 4.1 🔴 必须完成（核心功能缺失）

#### 1. 人岗匹配算法（MockMatcher 替换）

- **现状**：`MockMatcher.assess()` 返回 `score=null, decision="not_evaluated"`
- **需要**：实现真实的多维度匹配打分逻辑
- **涉及维度**：技能匹配、知识匹配、经验匹配、通用能力
- **接口契约**：
  ```python
  def assess(self, candidate: Profile, job: Profile, options: dict) -> dict:
      # 返回: score, decision, strengths, gaps, learning_path, document_evidence, graph_evidence
  ```
- **实现位置**：新建 `backend/app/infrastructure/matching/` 或 `backend/app/algorithms/`
- **注册位置**：[wiring.py](../backend/app/infrastructure/wiring.py) 第 116 行替换 `MockMatcher()`

#### 2. 报告生成器（MockReportGenerator 替换）

- **现状**：`MockReportGenerator.generate()` 返回 `sections=[]`
- **需要**：基于匹配结果生成结构化报告（中文）
- **接口契约**：
  ```python
  def generate(self, match: MatchAssessment, language: str) -> dict:
      # 返回: sections（包含标题、内容、建议等）
  ```
- **实现位置**：新建 `backend/app/infrastructure/report/`
- **注册位置**：[wiring.py](../backend/app/infrastructure/wiring.py) 第 118 行替换 `MockReportGenerator()`

#### 3. 数据持久化

- **现状**：`InMemoryResourceRepository`，服务重启后所有文档、画像、匹配记录丢失
- **需要**：接入关系型数据库（SQLite 最轻量 / PostgreSQL 生产级）
- **涉及实体**：`SourceDocument`, `Profile`, `MatchAssessment`, `KnowledgeGraphSnapshot`, `GeneratedReport`
- **实现位置**：新建 `backend/app/infrastructure/database/`
- **注册位置**：[wiring.py](../backend/app/infrastructure/wiring.py) 第 54 行替换 `InMemoryResourceRepository()`

### 4.2 🟡 应该完成（提升竞争力）

#### 4. LLM 抽取链路稳定性

- **现状**：Ollama 可选但非默认，模型不可用时静默降级为 mock
- **需要**：
  - 确保 Ollama 服务稳定运行
  - 前端 Dashboard 的 LLM 状态卡片能准确反映真实状态
  - 画像接口返回的 `warnings` 需在前端展示给用户
- **验证命令**：
  ```bash
  curl http://127.0.0.1:11434/api/tags        # Ollama 模型列表
  curl http://127.0.0.1:8000/api/v1/capabilities  # 后端能力状态
  ```

#### 5. 文档检索器（MockDocumentRetriever 替换）

- **现状**：`MockDocumentRetriever.retrieve()` 返回 `evidence=[]`
- **需要**：基于文档内容的向量/词法检索
- **优先级**：低于匹配算法，但对 RAG 问答质量有直接影响

#### 6. 岗位演化分析（MockPositionEvolution 替换）

- **现状**：`discover` 和 `delta` 均返回空结果
- **需要**：对比不同时间点的岗位画像，发现技能需求变化
- **优先级**：比赛加分项，非核心

#### 7. Dashboard 统计数据真实化

- **现状**：[Dashboard.jsx](../frontend/src/pages/Dashboard.jsx) 第 71-76 行硬编码统计数据
  ```javascript
  setStats({ totalMatches: 128, avgScore: 76, totalDocs: 45, uptime: "99.9%" });
  ```
- **需要**：后端提供统计接口，或前端从已有接口聚合计算
